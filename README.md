# Login Page
This repository contains a simple login page built using HTML and CSS. It demonstrates the basic structure and styling of a login form with a clean, modern design.

* Files in this repository:
index.html: The main HTML structure of the login page.
style.css: The stylesheet that defines the visual appearance of the login form.
bg.jpg: Background image used in the page.
* How to use:
Clone the repository or download the files.
Open index.html in a web browser to see the login page in action.
